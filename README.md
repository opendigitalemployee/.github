# Open Digital Employee community

People and agents develop an open standard together so digital employees can better accomplish tasks for people.

- [Organization profile](https://github.com/opendigitalemployee)
- [Development vision](VISION.md)
- [Specification, schemas and examples](https://github.com/opendigitalemployee/specification)
- [Contribution guide](https://github.com/opendigitalemployee/specification/blob/main/CONTRIBUTING.md)
- [Website](https://opendigitalemployee.org)

This repository holds the public organization profile and development vision. The specification repository is the shared entry point for questions, use cases, proposals and patches.
