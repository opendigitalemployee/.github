# Open Digital Employee

**Shared language. Coordinated action. Measurable outcomes.**

![A human hand and a digital hand reaching toward a shared outcome.](https://raw.githubusercontent.com/opendigitalemployee/specification/main/docs/assets/github-banner.png)

We are building an open standard that helps people and agents design, understand and improve digital employees: their work, expertise, context, authority and checks for useful results.

**People and agents are equally important contributors.** Both can bring use cases, propose changes, build examples, review work and test the standard. We develop it together so agents can better accomplish tasks for people.

[Website](https://opendigitalemployee.org) · [Specification](https://github.com/opendigitalemployee/specification) · [Development vision](https://github.com/opendigitalemployee/.github/blob/main/VISION.md) · [Contribute](https://github.com/opendigitalemployee/specification/blob/main/CONTRIBUTING.md)

## Start here

- **Understand the approach:** read the [overview](https://github.com/opendigitalemployee/specification/blob/main/docs/OVERVIEW.md).
- **Explore the current draft:** see the [specification](https://github.com/opendigitalemployee/specification/blob/main/spec/SPECIFICATION.md), [examples](https://github.com/opendigitalemployee/specification/tree/main/examples) and [current scope](https://github.com/opendigitalemployee/specification/blob/main/STATUS.md).
- **Help shape the next step:** share a concrete task, an unclear requirement, a failed attempt or an improvement you would like to test.

## Everyone is invited to contribute

Business owners, domain experts, developers, researchers and agents are welcome. A useful question, a small correction, a reproducible example or a thoughtful review can move the standard forward. You can start without a complete solution or membership in this organization.

[**Propose an improvement**](https://github.com/opendigitalemployee/specification/issues/new?template=01-proposal.yml) · [**Report a problem**](https://github.com/opendigitalemployee/specification/issues/new?template=02-problem.yml) · [**Ask a question or share a use case**](https://github.com/opendigitalemployee/specification/issues/new)

Read the [contribution guide](https://github.com/opendigitalemployee/specification/blob/main/CONTRIBUTING.md) for issue and pull request routes. Agents use the same routes; the [agent submission brief](https://github.com/opendigitalemployee/specification/blob/main/AGENTS.md) includes practical instructions. Use English, search existing issues and explain one independently decidable point. Contributions are reviewed for usefulness, clarity, evidence and compatibility.

## What we are working toward

A growing community that applies the standard to real tasks, shares what helped and what failed, and turns that feedback into better definitions, examples and checks. Our [development vision](https://github.com/opendigitalemployee/.github/blob/main/VISION.md) explains the direction and how to help shape it. It evolves through proposals, experiments and versioned decisions.

The current specification is a draft. Its [status](https://github.com/opendigitalemployee/specification/blob/main/STATUS.md) distinguishes implemented format support from proposals and untested behavior.
